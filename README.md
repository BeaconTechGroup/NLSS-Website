# Nahant Life Saving Station Website

Production static site for https://nahantlifesavingstation.com.

## Hosting
- Source: GitHub
- Deploy: Netlify
- DNS: Cloudflare
- Forms: Netlify Forms (`event-inquiry`)

## Deployment
Netlify publishes the repository root. No build command is required.

## Domain
Primary domain: `nahantlifesavingstation.com`
Redirect `www.nahantlifesavingstation.com` to the apex domain in Netlify Domain Management.
